# Decisions — memory-map

- D001 — Avalonia for the desktop UI — active
- D002 — Native APIs, not WMI, for the 1 s sampler — active
- D003 — A process tile's size is its private working set — active
- D004 — dotnet format, xUnit v3 on Microsoft Testing Platform, local check script — active
- D005 — One node tree for the breakdown; the sampler tags each process's kind — active
- D006 — xUnit v3 pinned to 3.2.2 for Avalonia's headless test runner — active
- D007 — Scene arrangement, hit-testing and tooltip text live in Core, not the UI — active
- D008 — Process actions re-check the start time and never end several processes at once — active
- D009 — Drill-down keeps a chain of node keys and falls back to the nearest ancestor — active
- D010 — History keeps one point a second for an hour, with every app's size — active
- D011 — The low-memory alert warns once, re-arms 2 points higher, and shows its own window — active
- D012 — Chart lines use the validated categorical palette, and an app keeps its slot — active
- D013 — Settings live in %APPDATA%\MemoryMap\settings.json and save on every change — active
- D014 — The installed app is one self-contained, uncompressed, untrimmed exe — active
- D015 — The app renders in software, not on the GPU — active
- D016 — A Settings option slows sampling while the window is hidden; off by default — active
- D017 — The map redraws on every refresh; skipping unchanged frames was measured and dropped — active
- D018 — Startup entries come from the Run keys, Startup folders and Store tasks, with Explorer's StartupApproved flags — active
- D019 — Store apps' startup tasks are read from the AppModel registry and package manifests — active
- D020 — An entry that starts a host program (cmd, rundll32, a script host) is credited with no processes — active
